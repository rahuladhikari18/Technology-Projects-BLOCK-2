## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?
_ANSWER = If two PCs have the same IP address, an IP address conflict will occur. This can cause network connection problems because the network will not be able to identify the correct computer. Both computers may lose access to network services.

### 5.2 Why do we use a switch instead of directly connecting PCs together?
_ANSWER = We use a network switch because it allows multiple computers to connect and communicate with each other easily. It sends data to the correct device using MAC addresses. It also makes the network easier to expand and manage compared with connecting computers directly.

### 5.3 What does the subnet mask 255.255.255.0 indicate?
_ANSWER = The subnet mask 255.255.255.0 means that the first three parts of the IP address identify the network, while the last part identifies the individual computer.It provides 254 usable IP addresses for devices in a standard IPv4 subnet.
