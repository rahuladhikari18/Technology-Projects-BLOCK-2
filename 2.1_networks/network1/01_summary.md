## 📘 1. Summary of the Task
Describe the purpose of this activity in your own words:  
- What is the goal of the lab?  
- What network are you expected to create?

ANSWER = The main goal of this lab is to understand how computer networks are designed, created and configured. The activity involves building a network that allows different devices to communicate and share information with each other. I am expected to create a small computer network using devices such as computers, switches and routers, configure IP addresses and establish connections between the devices. Finally, I will test the network to make sure all devices can communicate successfully.
