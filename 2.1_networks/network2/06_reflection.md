
## 🧠 6. Reflection

Answer in full sentences:

1. What are the advantages of DHCP over static IP assignment?
 ANSWER = DHCP saves a ton of time and effort by automatically assigning IP addresses to devices, whereas static IPs have to be manually configured on every single machine. It also prevents human error like accidental IP conflicts, and it efficiently manages a pool of addresses by recycling them when devices disconnect.
  
2. How does DNS improve usability in a network?
ANSWER = DNS makes the network much easier to use by translating complicated numerical IP addresses into friendly, memorable domain names. Instead of having to type out an IP address to access a server or website, users can just type a simple name, which is far more intuitive.
  
3. What would happen if the DHCP server went offline?
ANSWER = If the DHCP server went offline, new devices joining the network wouldn't be able to get an automatic IP address, leaving them unable to communicate. Devices that already have a leased IP could keep using it temporarily, but once their lease expired, they would lose connectivity too.
  
4. What part of this activity did you find easy or challenging? Why?
ANSWER = I found setting up the automatic configurations pretty straightforward because the interface made it easy to toggle on. However, troubleshooting why a client wasn't picking up a lease right away was a bit tricky and required double-checking the scope settings.
