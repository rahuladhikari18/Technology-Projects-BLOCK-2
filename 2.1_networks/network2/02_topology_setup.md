
## 🗺️ 2. Network Topology Setup

### 2.1 Description  
Explain how you built the network topology (devices, cabling, layout).
ANSWERS = I created a simple star topology network using Cisco Packet Tracer. The network consists of five PCs connected to one central switch using Ethernet straight-through cables. Each computer is connected directly to the switch, which allows the devices to communicate and share data within the same network. I arranged the devices clearly in the workspace to make the network easy to understand and manage. Finally, I checked the connections to ensure that the network was correctly connected.
